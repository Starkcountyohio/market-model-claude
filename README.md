# market-model-claude

QC and review tooling for Stark County Auditor's 2026 market model cycle.

**Where things live:**
- **Code** — this git repo (clone to a local folder OUTSIDE OneDrive)
- **Data** — the OneDrive-shared `Market Model Claude` folder; the `MARKET_MODEL_DATA` env var bridges the two (see `config.py`)
- **Outputs** — also land in the OneDrive folder so both collaborators see them

**Start here:**
- New to the project? Read `CLAUDE.md` for context (cycle parameters, cluster scheme, Track 1 findings).
- Setting up your machine? Read `BETHANY_SETUP.md` for click-by-click steps.
- Working with Claude Code? `CLAUDE.md` is auto-read on session start; no setup needed.
